Diccionario de datos

id - integer - identificador numerico
fecha - string - fecha en la que se realizo 
cliente - string - identificador
producto - string - nombre del producto
ciudad - string - ciudad de destino
cantidad - integer - cantidad de producto
precio - integer o float - precio del producto


Problemas                              desicion

ciudades con espacios y minusculas     normalizar antes de comparar
clientes repetidos                     es valido: se usa en S5 y S6
