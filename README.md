# cafe-origen-analitica

## Que es
Proyecto que analiza el historial de ventas de una tienda de cafe: total vendido, ventas por ciudad, unidades por producto y productos que mas generan.

## Como ejecutarlo
Necesitas Node.js instalado.

    node src/reporte.js

## Que preguntas responde
- Cuanto se vendio en total y cual es el ticket promedio?
- Cuanto se vendio en cada ciudad?
- Cuantas unidades se vendieron de cada producto?
- Cuales son los 3 productos que mas generaron?
- Cuanto se vendio en un dia especifico?
